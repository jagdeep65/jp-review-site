# Gadget Review Site

## Description
A platform for reviewing the latest gadgets. It allows users to see detailed reviews of gadgets and includes affiliate links for purchasing them.

## Features
- Gadget Reviews
- Affiliate Links to Purchase Gadgets
- Search and Browse Reviews by Category

## Installation
1. Clone this repository.
2. Upload it to your web hosting platform or run it locally using a server like XAMPP or WAMP.
